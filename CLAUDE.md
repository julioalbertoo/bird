# Instrucciones del proyecto

## Git

- **Pushear siempre a `main`.** El usuario lo pidió explícitamente: no
  trabajar en ramas `claude/*` ni abrir pull requests salvo que lo pida.
  Commitear directamente sobre `main` y hacer `git push -u origin main`.
- El workflow `.github/workflows` sube la versión automáticamente en cada
  push a `main`; usar `[skip version]` en el mensaje si hay que evitarlo.

## Idioma

- Commits, comentarios de código y README en español, como el resto del repo.
